# Minesweeper

A Minesweeper game I built with HTML, CSS, and JavaScript. I gave it a navy and sakura pink theme with falling cherry blossom petals.

Play it here: https://thephamj.github.io/sakura-minesweeper/

## How to play

Left click to reveal a square, right click to flag a mine. On a phone, long press to flag. There are three difficulties: beginner, intermediate, and expert.

## Running it locally

Download the files and open index.html in your browser.

## Files

- index.html: the page
- style.css: the styling
- game.js: the game logic
